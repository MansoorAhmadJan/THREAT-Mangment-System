# Threat Management System

An ongoing security-focused software learning project exploring the organization and management of cybersecurity-related information.

## Project status

This is a work in progress. Development, documentation and security review are ongoing. It is not intended to represent a production-ready security product.

## Learning objectives

- Organize information into a structured application.
- Build foundational software engineering skills.
- Apply secure development principles and document improvements over time.

Further documentation will be added after the relevant development and review milestones are complete.
